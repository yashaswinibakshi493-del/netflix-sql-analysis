# 📊 Netflix Power BI Dashboard

This Power BI dashboard presents the key findings from the Netflix Movies and TV Shows dataset.

The dashboard was created to explore Netflix content distribution, ratings, release trends, countries, and other key metrics.

## 🎯 Dashboard Objectives

- Analyze the distribution of Movies and TV Shows
- Explore content ratings
- Analyze release-year trends
- Understand country-wise content distribution
- Examine movie and TV Show duration
- Present SQL-derived insights visually
